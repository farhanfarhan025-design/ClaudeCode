# Market Intelligence

A 23-agent research team for Indian equities, run as paper calls with a scorecard.
Analysis only, never investment advice.

- `Market-Intelligence/daily/RUNBOOK.md`: what the evening job does, step by step
- `Market-Intelligence/daily/TEAM.md`: the roles
- `Market-Intelligence/scorecard/`: grades every call against NSE closes, excess over NIFTY
- `Market-Intelligence/daily/reports/scorecard.md`: the latest scorecard
